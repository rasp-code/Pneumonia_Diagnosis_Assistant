# Pneumonia diagnosis assistant from chest X-rays :
- Complete pipeline: image validation, pneumonia detection, report generated by an LLM (Groq API), handoﬀ to a human
expert when uncertain.
- Validation: fine-tuning of Azure Custom Vision on 840 rebalanced images. Detection: DenseNet121 with transfer
learning, 5,200 X-ray dataset, class weighting, preprocessing and augmentation built into the model.
- Cloud deployment (Azure) and oﬄine edge deployment (Docker, Ollama). Multi-agent orchestration (AutoGen).
